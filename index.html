Good questions

Before you
get started.

A few helpful answers about MicroService Tools, how the utilities work, and what to keep in mind when using them.

i

Have another question?
Check the documentation for the specific tool, if available, to understand its options and limitations.

01 What is MicroService Tools?

MicroService Tools is a collection of browser-based utilities for common tasks such as text and configuration conversion, password generation, hash calculation, colour contrast checking, and other developer or productivity workflows.

02 Are these tools free to use?

The tools are hosted as part of a publicly accessible website. Check the individual tool and its associated terms for any usage restrictions or additional conditions.

03 Do I need to install any software?

No separate installation is generally needed for browser-based tools. Open the relevant page in a supported, up-to-date browser and use the available interface.

04 Can I use these tools on my phone?

The page layouts are designed to adapt to different screen sizes. However, individual tools may have different usability requirements, so a desktop browser may be more convenient for some tasks.

05 Is my input data uploaded to a server?

Data handling depends on how each tool is implemented. Some browser-based operations can run locally, but you should not assume every tool processes data exclusively on your device. Check the specific tool's implementation and privacy information before entering sensitive data.

06 Can I use the generated output in my projects?

Output from utilities such as text converters, UUID generators, and formatting tools can generally be copied into your projects. Make sure the output meets your project's requirements and verify any security-sensitive or production-critical values.

07 What should I do if a tool doesn't work?

Check that your browser is up to date, confirm that your input is valid, and try reloading the page. If the problem persists, check the relevant project repository for known issues or troubleshooting information.

08 Are the tools suitable for sensitive information?

Avoid entering passwords, private keys, personal information, confidential business data, or other secrets unless you have verified how the particular tool processes and handles that information. Browser-based does not automatically mean privacy-safe.

09 Do I need an account to use the tools?

These pages are designed as directly accessible web utilities. If a particular tool requires an account or external service, follow the instructions displayed on that tool's page.

10 How can I suggest a new tool or improvement?

You can visit the MicroService Tools repository to explore the project and, where appropriate, submit an issue describing your suggestion or a problem you've encountered.
